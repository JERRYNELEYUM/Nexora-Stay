Hotel details

Staff accounts

Each staff member signs in with their own PIN, checked on this device. Admins have full control; Assistant Managers can see and do almost everything but can't delete, void, cancel, manage staff, or change cloud sync; front-desk staff can take bookings and handle billing.

NameRoleStatus

Hotel details, Reports, Payroll and Spending can only be seen by an administrator or assistant manager. Staff accounts and cloud sync can only be changed by an administrator.

Cloud sync

Optional. This app works fully offline on its own — nothing here is required. If you set up the small companion backend (see the README), this device will push its changes up and pull down changes from other devices whenever it has an internet connection, so the hotel owner can see live activity from anywhere.

Not set up.

Only an administrator can view or change the backend URL and sync key.

Data & backup

This device's data lives in this browser first and foremost. Export a backup regularly, especially before clearing browser data or switching computers — cloud sync (if set up) is a second copy, not a replacement for your own backups.
